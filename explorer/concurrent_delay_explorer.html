How each answer is worked out

The programme is treated as a causal model. For any combination of the two delays it gives the delay to completion against the as-planned date. Each legal approach is then a rule applied to the same three numbers: the delay the employer's event would cause alone, the contractor's alone, and both together.

  • Actual-delay test: an employer delay counts only if it causes actual delay to completion as then scheduled (Adyard [2011] EWHC 848 (Comm) paras 279–299; Saga Cruises [2016] EWHC 1875 (Comm) para 251). If it does, the contractor's concurrent delay does not reduce the extension (Malmaison; Walter Lilly [2012] EWHC 1773 (TCC) para 370; Thomas Barnes [2022] EWHC 2598 (TCC) paras 118 and 148). This is the only rule here that matches all five English cases. It was written after reading those judgments, so the match shows consistency, not independent prediction.
  • As-planned impact: impacts the employer's delay on the as-planned programme and ignores timing. Adyard (para 264) and Saga (para 249) reject this kind of theoretical delay.
  • Overlapping windows: any delays whose effects overlap in time are concurrent. A broad reading of the “felt at the same time” wording in Adyard para 279.
  • Strict sequence: only delays that start on the same day are concurrent. Otherwise a later employer delay earns time only for the delay it adds on top. Some commentators attribute this to Adyard, but the judgment states the test above.
  • NEC4 (clause 63.5, reading to verify): each compensation event is assessed prospectively against the programme at the time, and time and money go together.
  • City Inn [2010] CSIH 68 (Scotland): a dominant cause takes the period. Otherwise the shared days are apportioned by relative culpability.
  • Cyden-style clause (North Midland v Cyden Homes [2018] EWCA Civ 1744): the contract excludes concurrent delay, so only days the employer alone caused count. This gives the same number as a but-for test.
  • Money under every approach follows only days that would not have been lost but for the employer (Keating 9-105, adopted in Thomas Barnes para 118).
